# Hussein Shalaby — Portfolio

Computer Engineering student & graphics programmer | University of Padua

**Live site: https://husseinhafez1.github.io**

Jekyll-based portfolio built with the [minima](https://jekyllrb.com/docs/themes/#minima) theme, inspired by [wallisc.github.io](https://github.com/wallisc/wallisc.github.io).

## Contents

| Page | Description |
|------|-------------|
| Home (`index.markdown`) | Short intro + featured renderer screenshot |
| Projects (`projects.markdown`) | Full project details with screenshots |
| Blog (`blog.markdown`) | Write-ups (empty for now, posts coming) |
| Open Source (`open-source.markdown`) | OSS contributions (e.g. Google Filament) |
| Resume (`resume.markdown`) | Embedded `Hussein_Shalaby-1.pdf` |

## Run locally (Jekyll)

Requires [Ruby](https://www.ruby-lang.org/) (2.7+), Bundler, and Jekyll.

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000`.
